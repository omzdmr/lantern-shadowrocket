# Shadowrocket Free Subscription Mirror

Bu repo, public bir ücretsiz node aboneliğini saatlik olarak aynalar.

## Shadowrocket URL

China Telecom tarafında GitHub Raw sorun çıkarırsa jsDelivr adresini kullan:

`https://cdn.jsdelivr.net/gh/omzdmr/lantern-shadowrocket@main/output/sub.txt`

Raw yedek:

`https://raw.githubusercontent.com/omzdmr/lantern-shadowrocket/main/output/sub.txt`

## Güncelleme

GitHub Actions her saat kaynak aboneliği kontrol eder ve değişmişse `output/sub.txt` dosyasını günceller.

## Uyarı

Bunlar üçüncü taraf public proxy node'larıdır. Güvenilirlik, hız ve gizlilik garanti edilmez. Bankacılık, ödeme veya hassas hesap işlemleri için kullanılmamalıdır.
